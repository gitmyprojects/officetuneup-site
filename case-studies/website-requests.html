My own business

Website inquiries sit unnoticed

This website's own request form

The situation

Office Tune-Up Consulting needed a way for business owners to ask for a free Tune-Up Check from this website.

Many small business websites simply list an email address. That address soon collects spam, and a real request can sit unnoticed in a busy inbox.

What changed

The Contact page has a short request form. Each request is checked, saved in a secure database, and an email alert goes out with the details. Hitting Reply on the alert answers the person who asked.

Spam is filtered out quietly, without making visitors solve a puzzle. The whole setup runs on Microsoft Azure's free tiers, so it costs nothing at this size.

Before

  1. Email address posted on the site
  2. Spam and real requests mixed together
  3. A request gets missed

After

  1. Visitor fills in the request form
  2. Request checked and saved
  3. Email alert with the details
  4. Reply straight from the alert

What it meant for the team

  • No request depends on someone happening to notice an email.
  • Every request is kept in one place, with when it arrived and its status.
  • Replying takes one click from the alert.

Built with: Azure Static Web Apps, Azure Functions, Azure Cosmos DB, Azure Communication Services
