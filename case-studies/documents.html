Demo company

Staff use outdated procedures

One home for every procedure

The situation

At Lumen Photonics, the problem came from a quality audit: an operator followed an outdated work instruction because an old copy was still sitting on a shared drive.

Procedures lived in several places, in several versions, with no clear owner.

What changed

Procedures and work instructions now live in one library. Each document must have an owner, a department and a next review date before it can be saved.

Drafts stay hidden while they're being revised. Everyone else only ever sees the current approved version, and every past version is kept along with who approved it.

Before

  1. Copies on several shared drives
  2. Which one is current?
  3. The old version gets used

After

  1. One library for every procedure
  2. Drafts hidden until approved
  3. Everyone sees the current version
  4. Reviewed once a year

What it meant for the team

  • Staff find the current version in one place, every time.
  • Authors can revise a document without confusing anyone.
  • Every document comes up for review once a year instead of going stale.
